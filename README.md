# Сравнение всех лабораторных (Labs 1–5)

![comparison_all_labs](lab5/comparison_all_labs.png)

## Что внутри
- `train.csv`, `test.csv` — исходные данные конкурса (классификация и регрессия).
- `lab1` … `lab5` — ноутбуки с поэтапным пайплайном и артефактами (скейлеры, выбранные фичи, лучшие параметры, сабмиты).
- `lab5/comparison_all_labs.png` — итоговая визуализация всех метрик.

## Пайплайн (общее для всех работ)
1. **EDA и подготовка**: проверка пропусков/типов, разбиение признаков на числовые/категориальные, стратифицированный train/val split или кросс-валидация.
2. **Масштабирование**: `StandardScaler` / `RobustScaler` (подобранные параметры лежат в `step3_*`), чтобы стабилизировать KNN/линейные модели и не завалить деревья выбросами.
3. **Базовые модели**: 
   - Классификация: Lab1 KNN → Lab2 Logistic → Lab3 Decision Tree → Lab4 Random Forest → Lab5 Gradient Boosting.
   - Регрессия: KNN → Ridge/Lasso/ElasticNet → Decision Tree → Random Forest → Gradient Boosting.
4. **Feature selection**: Boruta + RFECV (артефакты `step5_*`), чтобы убрать шум и сократить пространство признаков.
5. **Оптимизация гиперпараметров**: `Optuna` / перебор (`step6_*`) с метриками F1/Accuracy для классификации и RMSE/R² для регрессии.
6. **Кросс-валидация и сравнение**: все результаты сохраняются в `step4_*`/`step6_*`, финальные сравнения и выводы — в `lab5/Freimvorki_5.ipynb` и на графике выше.
7. **Сабмиты**: для каждой лабораторной — `submission_*.csv` (sklearn и custom реализации) с Kaggle score.

## Почему это работает
- Масштабирование + стратификация снижают дисперсию оценок и предотвращают «перекос» классов.
- Boruta/RFECV убирают шумовые фичи → модели проще и устойчивее.
- Optuna подбирает глубины/кол-во деревьев/learning_rate, что даёт прирост F1/RMSE без переобучения.
- Сравнение baseline vs improved фиксирует прирост от фичер-отбора и тюнинга.
- Кросс-валидация на каждом шаге + проверка на Kaggle показывают, где возможное переобучение (см. сильный гэп у GB в Lab5).

## Итоги (см. график)
- **Лидеры классификации**: Random Forest (CV 0.8441, Kaggle 0.77511), Gradient Boosting чуть ниже Kaggle из-за переобучения.
- **Лидеры регрессии**: Random Forest (RMSE 14.34, R² 0.5350), далее Decision Tree.
- Gradient Boosting требует сильнее регуляризовать (меньше `learning_rate`, early stopping, min_samples_leaf).
